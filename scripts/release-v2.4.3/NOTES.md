# Kujira 2.4.3-rc.1 测试候选

来自 `test/v2.4.3`；本次仅发布预发布包，待用户验证后再转正式版。现有正式版仍为 2.4.2。

- 修复 OpenAI 本月费用遗漏当天：Costs 使用完整 UTC 日的排他结束边界，费用按账户或项目汇总，不按对话模型筛选。
- 移除模型选择与模型价格编辑，修正目录首个 `gpt-4` 被误示为当前模型；切换同账户模型保留未保存输入和折叠状态。
- OpenAI 暂无已确认的官方实时余额查询接口，继续显示费用；官方余额页面入口仅放设置页，气泡布局保持不变。
- 合并账户描述请求，前台选择不再等待会话历史或角色读取；迟到结果不覆盖新选择。
- 配置保存失败后清理临时文件，保留原配置、角色、记忆及日记内容。

## 安装测试包

在 DSH **插件 → 安装第三方插件 → 包名或地址** 中填写：

```text
https://github.com/Tests4gptplay/dsh-kujira-persona/releases/download/v2.4.3-rc.1/dsh-kujira-persona-2.4.3-rc.1.tgz
```

安装后核对版本为 **2.4.3-rc.1** 并启用。若宿主提示需要重启，保存当前任务后重启 DSH；不要删除 DSH 数据目录。

本候选不发布到 npm。`SHA256SUMS.txt` 提供安装包校验值。

## 已验证

- 相同现有查询凭据和项目的官方只读 API 对照，确认旧日期边界遗漏当天；修正后的实际适配器返回当天费用。
- 123 项针对性回归，包括 UTC 月年边界、分页、账户路由、迟到结果、会话历史、原子保存失败恢复及日记摘要保留。
- 真实 Chromium 设置页交互与 SSR；余额入口仅位于设置页，未改气泡布局。
- 发布流程重新运行回归、逐文件核对安装包源码，并从解包目录验证账户契约。

真实目标机器的安装后效果由本次用户测试确认。
