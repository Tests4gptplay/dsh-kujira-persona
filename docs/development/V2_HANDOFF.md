## 保持的产品要求

- 始终只有一只桌宠，随当前对话选用的模型换形象；同一家族不同版本延续同一人物。
- 桌宠可选且默认关闭，在插件详情中配置。关闭桌宠不影响世界观、人设和对话修改。
- world 保存公共印象和人物关系，persona 保存角色自身性格与个人记忆。用户的明确选择优先。
- 角色选择、档案、记忆、素材和用户绑定保持现有行为；资料不能因文案整理被删除或重置。
- DeepSeek 余额与 Codex Native 套餐按实际接入查询；普通 GPT API 不按 Codex 套餐显示。工作统计直接沿用 DSH 的已有统计，分别显示任务状态、上下文占用和账户数据。
- 用户要求先完成代码，再单独讨论美术。已有桌宠素材仍为功能联调用占位，不作为美术定稿。
- 测试、模拟数据、诊断脚本和发布辅助材料只留在 QA，不进入产品安装包。

## 文案维护

README、插件介绍、示例和后续版本说明只讲使用所需的信息，不逐项解释内置角色的选择条件。示例使用通用角色描述；实际聊天自然呈现当前人物，不播报内部流程。2.0.0 的发布文案沿用这一原则。
