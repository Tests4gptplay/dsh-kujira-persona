# Kujira 2.0.3

- 新增右键菜单：显示／隐藏桌宠、显示／隐藏气泡，以及同时关闭两者；全部隐藏后可从 Kujira 设置页恢复。
- 页面使用 DSH 菜单组件，Windows 原生菜单同步当前主题配色。
- 隐藏桌宠后释放原有占位，气泡仍可拖动到可用区域底部；优化缩放、长内容和小屏幕布局，隐藏桌宠时暂停其逐帧播放。
- 保留 2.0.2 的并行会话识别修复，以及现有角色动画、人物设定、记忆和模型绑定。

## 安装与升级

在 DSH 插件管理器中使用：

```text
github:Tests4gptplay/dsh-kujira-persona#v2.0.3
```

备用安装包：`dsh-kujira-persona-2.0.3.tgz`。已有版本卸载重装插件后重启 DSH 一次；保留 `.dsh/world`、`.dsh/persona` 和 `.dsh/personas` 中的设定与记忆。
