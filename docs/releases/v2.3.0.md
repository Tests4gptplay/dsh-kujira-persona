# Kujira 2.3.0

## 更新内容

- 更新桌宠思考、回复、书写与测试等动作，改善手部、道具与书页的连贯性。
- 通用工具状态使用持续操作循环，避免长时间停在单帧；各角色的具体任务动作继续保留。
- 无损压缩美术资源，保持像素、透明度、色彩信息及原尺寸。
- 修复日记并发写入的摘要竞争；追加中断后的重试使用恢复记录，避免重复写入。
- 保留 2.2.3 的档案、日记、睡眠整理与桌宠恢复修复。

## 安装与升级

从本 Release 下载 `dsh-kujira-persona-2.3.0.tgz` 和 `SHA256SUMS.txt`，核对 SHA256 后安装；也可使用固定 Git 标签 `v2.3.0`。

更新前先关闭桌面桌宠及提示气泡，再卸载旧包并安装新版。保留已有设定、记忆、桌宠配置与日记库；安装并启用后重启 DSH。具体步骤见 [README 安装和升级](https://github.com/Tests4gptplay/dsh-kujira-persona/tree/v2.3.0#安装和升级)。
