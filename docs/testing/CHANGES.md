# 改动与依据

新增平台适配的验收状态：Linux官方DSH Web已实际验证本文所列睡眠/取消/恢复及界面子项；跨平台companion是新增实现，Linux原生Desktop整体挂接与macOS原生窗口仍列实机验证要求。Windows原生保留既有路径，本候选剩余绑定项也按实机清单。

## 相对当前正式2.3.1的功能变化

- 增加桌面伴随窗口适配实现，页面内与原生桌宠路径分离，按平台处理窗口行为；目标系统绑定按[实机要求](LOCAL-VALIDATION.md)补验。[实现](../../pet/companion/)
- 扩展余额、套餐与工作统计的提供方适配和设置；按服务实际提供的数据展示，不把不同口径强合为同一余额。[实现](../../pet/usage.js)、[适配器](../../pet/usage-vendors.js)
- 睡眠整理可处理当前角色自己的Persona：读取、修改及新建，修改前备份，遇并发变化先重读；保留日记与整理独立开关。[实现](../../diary-sleep.js)、[档案实现](../../dossier.js)
- 完善设置中英文、Host主题跟随和模型联动；桌宠关闭时设置仍能跟随当前模型，后台OFF仍不轮询。[实现](../../pet/client.js)
- 修复多处程序错误，改善运行稳定性；补足取消、冲突及Host退出恢复的验证。美术媒体144文件与当前main一致，没有另换一套图片。[详细证据](CASEBOOK.md)

这些是当前正式源码到本候选的累计变化，不只最后一轮两个客户端修复；实际账户/平台范围以验收页为准，不把适配代码存在写成所有真实账户已验证。


| 原问题 | 依据 | 本候选修正 |
|---|---|---|
| 深色主题原生选择列表文字/背景对比不稳定 | 早前实际GUI观察 | select和option使用当前Host背景/文字变量并继承color-scheme |
| 桌宠关闭时设置中的模型路由不跟随当前选择 | 实际切模型结果与客户端提前返回逻辑 | 移除前端pet-enabled提前返回，保留当前session/页面可见保护和事件清理；后台OFF仍不查询、不启轮询/渲染 |
| 简介对角色、模型联动、日记等关系不够集中 | 对应主库/候选实现逐项核对 | 正向保留同家族连续、自定义预设、工作统计，并说明跟随DSH已选模型与日记功能；主库和候选能力分开 |

不重设计奶油色气泡，不改后台调度或授权，不新增接入能力宣传。介绍文案覆盖与正在运行的冻结包分离。
