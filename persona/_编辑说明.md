# 编辑说明

这个目录就是人设的正文。插件每轮把 `*.md` 按文件名顺序拼起来，塞进系统提示词。

**改完不用重装，也不用重启。下一句话就生效。**

---

## 一、加东西

### 加一条世界观 / 一条梗

新建一个文件，名字带序号：

```
persona/45-梗.md
persona/46-某位作者的世界线.md
```

序号决定它排在哪。数字之间留空，方便以后插。

### 加一条人设细节

优先追加到已有文件：

| 想加什么 | 加进 |
| --- | --- |
| 称呼、身份、种族 | `00-身份.md` |
| 外观、服装、道具 | `10-外观.md` |
| 性格、习惯、爱好 | `20-性格.md` |
| 说话方式、禁用词 | `30-说话.md` |
| 世界观分层 | `40-世界观分层.md` |
| 同事、关系 | `50-关系.md` |
| 自己编的设定 | `60-我们的原创设定.md` |

### 加一条「你要记住的」

```markdown
- 2026-10-22 · 她怕打雷
```

写进 `90-记忆.md`，或者在会话里敲 `/remember 她怕打雷`。

### 让 AI 自己改

会话里说一句「查到的新东西补进人设，冲突的把旧的改掉」，模型会用 `persona_edit` 动手：

| action | 做什么 |
| --- | --- |
| `append` | 新增一条，落进 `95/96/97` 或你指定的文件 |
| `replace` | 改掉旧的（要求原文唯一，改错了会报错） |
| `delete` | 删一段，或者删整个文件 |
| `list` | 看有哪些文件 |

改和删之前会自动留一份在 `.kujira-backup/`，删错了能捞回来。写不进去会明确报错。

## 二、规则

1. **只认 `.md`**。别的扩展名不会被读。
2. **`_` 或 `.` 开头的文件不注入**。说明文档、备份都放这一类。
3. **顺序 = 文件名字典序**。用两位数前缀：`00`、`10`、`20`……
4. **子目录不扫**。想留旧版就放 `_archive/`。
5. **删就是删**。删掉一个文件或一行，下一轮就不注入了。

---

## 三、写的时候守住三条

1. **原创要标日期**。自己编的设定写进 `60-我们的原创设定.md`，别混进世界观分层冒充原作。
2. **别人的世界线要署名**。谁写的、哪条视频、哪个作者——写清楚。
3. **授权是 CC BY-NC-SA 4.0**。非商用，署名链「上善无形 → ZipZipPipe」不能删。

## 四、怎么验证

在会话里：

- `/persona` —— 几个文件、多少字符、读的是哪个目录
- `/persona files` —— 这一次注入了哪些文件，各自多大、什么时候改的
- `/persona show` —— 直接看注入的全文
- `/persona sync` —— 把插件新版里的默认内容同步进来，只动你没改过的文件
- `/remember 一句话` —— 往 `90-记忆.md` 追加一条

改了没生效？先看 `/persona files` 里有没有那个文件，再看是不是 `_` 开头。

## 五、这个目录在哪

默认是 `~/.dsh/persona`（有 `DSH_HOME` 时是 `$DSH_HOME/persona`），首次运行自动铺一份内置人设。
想换地方，在 profile 的 `cordis.patch.yml` 里：

```yaml
- id: whale-persona
  name: dsh-kujira-persona
  config:
    personaDir: 'D:\my-persona'
```
