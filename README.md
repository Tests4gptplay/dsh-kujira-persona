# Kujira · AI 娘人设

**随 DSH 中选用的模型切换角色，在对话中继续养成自己的世界与人物。**

## 世界观与人物

**世界观**是大家共用的称呼、社区印象、梗和人物关系，让角色认识彼此。比如与 DeepSeek 鲸鱼娘聊天时，她也知道“猫猫”通常指 Gemini、“龙娘”指 GPT。故事发生在哪里、角色如何相处，都可以由你继续设定。

**人物**是每个角色自己的性格、喜好和记忆。切换模型家族时切换角色；同一家族的不同版本默认共用一个角色和已有记忆。内置多种 AI 娘基础预设，也支持通过对话创建与调整自己的角色。

默认自称使用 DeepSeek、GPT、GLM 等模型家族名称，平时自然说“我”。白龙、鲸鱼、猫猫等保留为形象和别称，不会要求角色用“XX娘”介绍自己。你另起名字或使用自定义角色时，就按你选定的称呼来。

预设只是起点。称呼、性格、关系和模型对应的角色都能改；与你的要求不同，就按你的来。

## 2.0.0：可选的模型联动桌宠

只显示一只桌宠：切换当前前台对话的模型，就让这一只换成对应形象；同一家族的不同版本沿用同一人物。用户明确指定的角色优先，通过对话修改模型绑定后，桌宠会跟随更新。其他会话和后台子代理的活动不会接管前台桌宠。

桌宠默认关闭，可以在插件详情中打开“启用桌宠”。支持页面内显示与 Windows x64 原生桌面窗口；页面位置和桌面位置分别保存。设置包括角色与气泡大小、活动程度、减少动态、提示音、位置重置，以及余额／套餐和工作统计各自的显示开关。关闭桌宠后，原有人设、世界观和对话修改功能仍可使用。

### 任务状态与动作

桌宠跟随待机、思考、查找、编辑、执行命令、检查、等待确认、完成和出错等阶段。暂时失败的工具会触发短暂反应，之后继续跟随当前工作；整轮任务终止出错时保留错误状态。需要用户回答或批准时，等待状态会持续到相应条件解除。

Web 和 Windows 共用动作时间线，从实际 PNG 图集中逐帧裁切播放，常规动作之间采用约 100 ms 的过渡。拖起与落地即时切换；减少动态时保持静止待机图，任务文字继续更新。GPT 已接入摸头、戳一下、碰尾巴、拖放和随机待机小动作；其他角色按已经完成的素材提供相应反应。

部分角色的思考、查找、编辑等状态会共用已经绘制的中性工作动作，完成或出错也可能使用中性单次动作。状态联动始终保留，专属动作的多少以当前素材为准。对于尚未明确性格的角色，优先采用普通阅读、工作、等待等功能动作。

GPT 当前有 16 个动作片段，DeepSeek 有 8 个，包括独立的思考、拖起和落地动作。其他角色使用已经接入的待机、工作和结果反应；MiMo 当前采用 7 个不同的原图姿态，等待复用眨眼，完成与出错为各自的单帧保持。功能状态数量不等于独立绘制的动画数量。

**当前动画图集是 AI 生成的候选美术，仍待最终审定。**造型依据 AI-gijinka 资料库和本轮角色参考，保留各角色的识别特征；动作、裁切、比例与实际桌宠尺寸下的观感分别检查。功能验证通过不等于美术已经定稿。来源与使用条件见 [桌宠说明](pet/NOTICE.md)。

### 工作气泡里的统计

启用“显示工作统计”后，工作气泡分三行显示当前前台会话的读数：**轮次与步骤、生成速度；累计 Token 与缓存命中；上下文已用比例**。缺少某项数据时省略，不用编造的数值占位。完成后可以继续看到本会话统计，切到新会话不会沿用旧会话的数字。

这些数字采用 DSH 底栏的统计口径：轮次和步骤是会话累计数，速度是已有解码时间和输出 Token 的统计值，不代表机器或套餐的速度上限；缓存读、缓存写、未缓存输入与输出不会重复相加。

**“上下文已用 100%”不是任务做完了，也不是套餐额度用完了。**任务状态、任务清单进度与账户信息分别显示。DeepSeek 按实际接入显示余额；已接入的 Codex Native 账户显示套餐窗口余量，普通 GPT API 不会被当成 Codex 套餐。没有相应账户接口时会说明暂不可用。

该显示复用 DSH 已有会话统计，不另外扫描聊天日志、不为工作统计增加定时轮询。余额／套餐有独立的查询与刷新设置；临时查询失败时，会保留并标明上次结果。本轮动画验证没有核实真实账户余额、付费模型消耗或套餐数值。

## 扩充和修改，直接在 DSH 聊天框里说

补充世界观、修改人物性格、创建原创角色、给自定义模型指定角色，都可以通过对话让 AI 完成，不必手动编辑文件。例如：

> 把龙娘的语气改得活泼一点，保存到她的人设里。

> 把“龙娘和猫猫每周五一起做甜点”补进大家共同知道的设定。

> 创建一个我自己的角色，性格温柔、说话简洁，让当前模型使用。

之后还可以继续修改角色的名字、性格和故事，或让其他模型也使用同一角色。通过对话保存后，后续聊天就会使用更新的设定，无须另外刷新或重启。

这里添加的是角色和模型之间的对应关系；尚未接入 DSH 的模型，先在 DSH 的模型设置中接入。

## 安装和升级

以下为 v1.6.2 的安装示例。2.0.0 开发分支尚未发布。

DSH Desktop：打开 **插件 → 添加插件**，输入：

```text
github:Tests4gptplay/dsh-kujira-persona#v1.6.2
```

安装、启用后重启 DSH 一次。已有旧版时，先在插件列表卸载旧包，再安装新版。**保留 `.dsh/world`、`.dsh/persona`、`.dsh/personas` 中的设定与记忆。**你已经修改过的档案不会被新版预设覆盖，可以通过对话选择如何补充新内容。无需 npm 账号。

Web 版安装命令：

```bash
dsh plugin --profile web add 'github:Tests4gptplay/dsh-kujira-persona#v1.6.2'
```

Web 与 Desktop 分别安装。[GitHub Releases](https://github.com/Tests4gptplay/dsh-kujira-persona/releases) 也提供备用 `.tgz` 安装包。

### Windows 安装提示 EPERM

若出现 `dsh-kujira-persona_tmp_* -> dsh-kujira-persona` 重命名失败：取消安装，完全退出 DSH（含托盘），打开 `%USERPROFILE%\.dsh\profiles\desktop\node_modules`，只清理本插件失败安装的临时目录和确认损坏的半安装项，再重新安装。正常目录不需要删除；目录链接只处理链接本身。

保留其他插件、profile 配置，以及上述人设和记忆目录，无需删除整个 `node_modules`、`package.json` 或 `pnpm-lock.yaml`。仍有问题可在 [Issues](https://github.com/Tests4gptplay/dsh-kujira-persona/issues) 附上脱敏错误日志。
