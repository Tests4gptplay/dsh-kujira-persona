# 改动与依据

| 原问题 | 依据 | 本候选修正 |
|---|---|---|
| 深色主题原生选择列表文字/背景对比不稳定 | 早前实际GUI观察 | select和option使用当前Host背景/文字变量并继承color-scheme |
| 桌宠关闭时设置中的模型路由不跟随当前选择 | 实际切模型结果与客户端提前返回逻辑 | 移除前端pet-enabled提前返回，保留当前session/页面可见保护和事件清理；后台OFF仍不查询、不启轮询/渲染 |
| 简介对角色、模型联动、日记等关系不够集中 | 对应主库/候选实现逐项核对 | 正向保留同家族连续、自定义预设、工作统计，并说明跟随DSH已选模型与日记功能；主库和候选能力分开 |

不重设计奶油色气泡，不改后台调度或授权，不新增接入能力宣传。介绍文案覆盖与正在运行的冻结包分离。
