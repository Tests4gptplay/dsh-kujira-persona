# 2.0.0 需求补充：未知模型使用星璃

用户于 2026-10-23 恢复开发，并明确要求：**未知模型统一用原创角色星璃（Stella / stella）做人设，同时使用星璃的桌宠形象。不是只换桌宠图片。**

## 实现目标

- 已识别的模型家族继续使用现有角色；同家族版本共享人物和记忆。
- 未被现有家族规则识别、也没有用户明确绑定的模型，默认使用 `stella` 的人物档案和记忆；多个未知模型默认共享这一个角色。
- 始终只有一只桌宠：当前模型变化时更新这一只的形象，不按模型、标签页或会话堆叠宠物。
- 用户已有的模型绑定、固定角色选择及明确关闭人设的选择优先；用户可继续通过 DSH 对话修改或绑定其他角色。
- 星璃采用 `Tests4gptplay/ai-gijinka-art-world` 中 `私设/星璃/README.md` 和 `私设/星璃/对话卡.md` 的原创设定。她是独立原创角色，不冒充未知模型的厂商或技术身份。
- 形象由助手继续创作：成年女性的 Q 版表现，烟栗色及肩发、浅茶色挑染、灰绿眼睛、奶油白与墨青服装、开口银环配暖金小珠胸针。先读取完整原设再完成资源。
- 星璃自身性格与记忆放个人档案；名字及供其他角色辨识的简短外界印象进入共同世界。私设不会被宣称为社区共识。
- 套餐、余额和计费展示仍依据实际 provider / model 接入，不因为套用星璃就继承其他账户数据。

## 验证范围

在 QA 分支验证：未知模型首次请求加载星璃、同一只桌宠换成星璃、对话修改后写入 `personas/stella`、新会话读回、显式用户绑定覆盖默认、显式 none 不被恢复成星璃、已知家族不受影响。模拟额度仅在 QA；运行安装包不包含测试、假数据或验证代码。

本补充取代早期交接里“未知模型不强套角色”的默认结果，以及用 `unknown` 占位图作为最终默认的方案。它只改变默认选择，不取消用户优先原则。

开发继续在 `feat/v2.0.0-single-model-pet`，测试在独立 QA 分支。未获新的发布授权前，不合并主线、不发布 2.0.0、不更新市场。
