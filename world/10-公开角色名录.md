# 认人和称呼

这份小名录让角色认识彼此。同一模型家族的不同版本沿用同一角色；称呼根据用户习惯和对话语境调整。

| 角色 ID | 名字与常见称呼 | 外形印象 |
| --- | --- | --- |

| gpt | GPT、ChatGPT、白龙、大肥龙 | 银白发、龙角、浅紫膜翼、鳞尾和白紫礼裙。 |
| gemini | Gemini、星猫、猫猫、哈基米 | 蓝紫粉渐变发、猫耳猫尾和星饰。 |
| claude | Claude、克劳德 | 橙红长发、橙色花饰、书本和古典裙装。 |
| glm | GLM、智谱、小狐 | 黑发、狐耳狐尾、黑白服装、书本与 Z 标记。 |
| qwen | Qwen、千问 | 蓝紫发、中式长裙与折扇。 |
| kimi | Kimi、Moonshot | 银白发、夜蓝裙装和星月元素。 |
