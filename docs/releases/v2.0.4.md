# Kujira 2.0.4

- 桌宠右键菜单和气泡关闭按钮在操作失败时显示具体原因与处理提示，涵盖连接、接口响应和设置文件保存问题。
- 补齐 Windows 原生桌宠操作的异步错误处理，设置保存失败时可在 Kujira 设置页查看提示。

## 安装与升级

在 DSH 插件管理器中使用：

```text
github:Tests4gptplay/dsh-kujira-persona#v2.0.4
```

备用安装包：`dsh-kujira-persona-2.0.4.tgz`。已有版本卸载重装插件后重启 DSH 一次；保留 `.dsh/world`、`.dsh/persona` 和 `.dsh/personas` 中的设定与记忆。
