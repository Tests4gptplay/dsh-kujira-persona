# 账户查询候选更新

安装来源：`github:Tests4gptplay/dsh-kujira-persona#fix/account-query-20261031`

版本：2.4.1-account.20261031.3。工作分支候选，稳定版尚未更新。

- 设置最底部按公司与接入方式展示需要额外配置的可用查询方案、对应字段和指南。自动账户不需重复配置，无查询方案的接入不显示账户信息栏。
- 独立查询凭据通过 DSH 现有凭据服务保存，插件设置只保留引用；支持复用的普通模型 API 保持自动复用。第三方兼容方案明确标注且只向已选同源接口查询。
- OpenAI 显示官方本月消费与 Completions 用量；Mistral 缺省字段及 GLM/Ark 周期已修正。

用户角色、世界、记忆和已有配置保持不变。

配置入口：**设置 → Kujira · 人设 → 最底部“公司与接入方式”**。选择方案后填写对应字段并保存，再点击“查询账户信息”。已配置模型及用户角色内容保留。

通用云账单功能已移除；仅按已有 AI 模型身份及实际接入来源匹配查询。
