# Kujira 2.0.0

Kujira 为 DeepSeek Harness 带来随模型切换的 AI 角色设定与桌宠，支持共享世界观、独立人物记忆和直接通过对话编辑。

## 新功能

- **模型联动桌宠**：在 Windows 桌面与 DSH 页面内显示单只角色，逐帧跟随思考、查找、编辑、命令、测试、等待、完成及出错等任务状态。
- **角色与世界观**：14 个模型家族及星璃，支持人物档案、关系、称呼和用户自定义模型绑定。
- **独立设置页**：通过「设置 → Kujira · 人设」调整角色和气泡大小、活动状态，打开人物文件夹并查看磁盘占用。
- **工作统计与账户信息**：任务轮次、步骤、Token、缓存和上下文使用情况，以及按实际连接显示的账户余额或套餐信息。
- **交互与动画**：拖动、落地、触摸反馈、提示音和随机待机；多角色动作图集共用 Web／Windows 播放逻辑。
- **升级与记忆**：原有用户设定、记忆与模型绑定继续保留，DeepSeek 档案可从旧目录平滑迁入。

## 安装

在 DSH 插件管理器中使用：
```text
github:Tests4gptplay/dsh-kujira-persona#v2.0.0
```

命令行（Web profile）：
```bash
dsh plugin --profile web add 'github:Tests4gptplay/dsh-kujira-persona#v2.0.0'
```

桌宠默认关闭，安装后可在「设置 → Kujira · 人设」中开启。
