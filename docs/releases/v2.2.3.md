# Kujira 2.2.3

- 保留手动删除的默认档案，改进损坏状态、角色绑定及备份恢复，修正旧记忆迁移优先级与外部编辑说明。
- 改进日记并行追加、重试记录与待整理内容保存，修复睡眠整理的取消、无进展重试及目录设置恢复。
- 改进 Windows 桌宠启动等待和取消处理，提供动画加载失败后的手动重试。

## 安装

更新前请关闭桌面上已显示的桌宠和提示气泡，再卸载旧包并安装新版；保留已有设定、记忆、角色绑定、日记库与插件设置。

Desktop：在 **插件 → 添加插件** 中输入 `github:Tests4gptplay/dsh-kujira-persona#v2.2.3`。

Web：

```bash
dsh plugin --profile web add 'github:Tests4gptplay/dsh-kujira-persona#v2.2.3'
```

也可下载 [2.2.3 安装包](https://github.com/Tests4gptplay/dsh-kujira-persona/releases/download/v2.2.3/dsh-kujira-persona-2.2.3.tgz) 与 [SHA256 校验文件](https://github.com/Tests4gptplay/dsh-kujira-persona/releases/download/v2.2.3/SHA256SUMS.txt)。Web 与 Desktop 分别安装；安装、启用后重启 DSH 一次。完整目录保留说明见 [安装和升级](https://github.com/Tests4gptplay/dsh-kujira-persona/blob/main/README.md#安装和升级)。
