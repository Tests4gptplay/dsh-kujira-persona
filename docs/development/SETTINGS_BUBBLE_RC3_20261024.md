# Kujira 2.0.0 · 设置入口与气泡大小 RC3

日期：2026-10-24。开发分支：`feat/v2.0.0-single-model-pet`。

## 已落实

- 使用 DSH 官方 `settings.section` 插槽新增 **Kujira · 人设** 导航栏。桌宠设置已从插件详情页移入此栏。
- 世界观、DeepSeek 基础人设、`personas` 人物档案根目录和每个角色目录均提供“打开文件夹”按钮。内置的星璃明确列在人物列表中，自定义角色也可访问。
- 路径来自插件实际运行配置（`worldDir`、`personaDir`、`personasDir`、可选 `sharedDir`），用户配置路径变化后继续按真实位置打开。
- 显示各顶层目录的实际字节数、每个角色的占用和全部合计；对重复或嵌套目录避免总计重复计算。
- 设置页打开时读取一次，按钮可手动刷新；文件夹列表和尺寸均不启动常驻扫描或轮询。
- 文件夹打开采用宿主系统文件管理器，Windows 为 `explorer.exe`；仅接受预先定义的顶层目录与安全角色 ID。首次打开尚未初始化的角色目录时，按现有人设播种流程创建资料。
- 设置底部提示：**修改世界观、人物性格、记忆或模型对应关系，请直接在 DSH 对话中告诉 AI；这里用于查看文件位置和占用空间。**
- 页面桌宠的气泡大小改为容器整体 `transform: scale(...)`，标题、任务、进度、工作统计、余额、间距和边框均同步缩放；角色大小设置独立。
