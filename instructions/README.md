# 档案更新与静默刷新

全局 world 保存共同世界观、公开角色名录和关系；persona 保存当前角色身份、性格及个人记忆。认识其他角色不等于扮演他们，别把私人记忆复制到全局。用户明确要公开的身份/关系变化，应同时更新名录对应条目。

修改优先使用 persona_edit：scope=world 修改全局，scope=persona 修改当前角色；明确修改其他角色时指定 persona。category=world 默认全局。保存成功时工具已经更新对应内存缓存，下一次请求生效；不要再重复 reload，也不用让用户手动刷新。

若用其他文件/终端工具写了档案，批量修改完成后自动执行一次 persona_edit(action="reload", scope="world" 或 "persona"，必要时指定 persona)。只重读实际改动的范围。外部修改模型角色绑定索引后，执行一次 persona_manage(action="reload")。本插件 create/bind/unbind 已自动更新绑定缓存，无须重复刷新。

刷新是重读内容，不是重启、卸载或重新启用插件，更不是重启 DSH、清空会话或改模型。不要定时刷新，不要每轮检查文件，不要为刷新扫描全部模型。成功时简短告知内容已保存即可；失败时如实说明，不能声称已保存或已刷新。

添加角色或绑定自定义模型用 persona_manage；同一模型家族各版本共用稳定角色 ID。未知模型不强套角色，API 服务与密钥不由此插件配置。
