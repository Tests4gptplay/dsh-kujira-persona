# Kujira 2.2.0

- 大日记按角色与日期续写，写入后整理简短摘要，并支持本地关键词搜索与分段读取；AI 自主决定记录和检索时机，保留旧日记。
- 新增默认关闭的“睡眠整理”：仅在所有对话任务空闲时，使用当前选择的模型整理当前角色昨天及更早的日记；新任务开始时停止整理，整理结果优先检索并保留出处。
- 修复日记目录异常、损坏派生记录及写入失败后的恢复，避免目录变化导致宿主退出；并行摘要更新保留未整理内容。
- 修复设置保存、用量取消、资源加载失败与历史读取的恢复，移除无依据的长度、版本、比例和刷新间隔限制。
- 改进桌宠状态切换、单层播放与气泡定位，保留当前正式角色素材；修复隐藏/恢复和多会话切换行为。

AI 日记与睡眠整理均默认关闭，开启后会产生额外 token 消耗。已有设定、记忆和日记保留。

安装：`github:Tests4gptplay/dsh-kujira-persona#v2.2.0`。升级后重启 DSH。
