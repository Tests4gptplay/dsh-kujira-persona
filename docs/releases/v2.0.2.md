# Kujira 2.0.2

- 修复多个任务并行时，切到正在运行的会话却显示“等待开始”、缺少工作统计的问题。
- 桌宠的角色、模型、任务状态和统计跟随当前选中的主会话；后台任务完成、乱序事件和侧栏子任务不会抢占显示。
- 补齐切换、重新启用及重连后的状态，保留等待确认、完成和取消的正确表现，避免重复播放同一次完成或出错反应。
- 现有角色动画、人物设定、记忆和模型绑定保持不变。

## 安装与升级

在 DSH 插件管理器中使用：

```text
github:Tests4gptplay/dsh-kujira-persona#v2.0.2
```

备用安装包：`dsh-kujira-persona-2.0.2.tgz`。已有版本卸载重装插件后重启 DSH 一次；保留 `.dsh/world`、`.dsh/persona` 和 `.dsh/personas` 中的设定与记忆。
