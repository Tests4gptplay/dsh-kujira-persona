# Kujira 2.3.1

## 修复

修复桌宠在 Windows 桌面与 DSH 页面内切换后消失的问题。显示位置直接切换即可生效，无需先取消再勾选“启用桌宠”。同一会话的启用状态与任务信息继续保留。

原生进程的迟到退出或启动错误只更新仍处于桌面模式的状态，不再覆盖已选中的页面模式。其他桌宠功能与美术资源保持不变。

## 安装

在 DSH Desktop 的“插件 → 添加插件”中直接粘贴：

```text
https://github.com/Tests4gptplay/dsh-kujira-persona/releases/download/v2.3.1/dsh-kujira-persona-2.3.1.tgz
```

升级前关闭可见桌宠及气泡，卸载旧包后安装新版；保留已有设定、记忆、桌宠配置和日记库。完整说明见 [README](https://github.com/Tests4gptplay/dsh-kujira-persona#安装和升级)。

## 回归验证

显示位置切换新增 9 项异步子进程回归：修复前 7 项失败，修复后 9 项通过；与原有回归合计 371 项通过、无跳过。覆盖双向往返、快速切换、旧进程迟到退出、启动未完成时切走和启动失败后的页面显示。

正式发布流程另运行 Windows 原生桌宠切换、文件锁与恢复检查，以及浏览器菜单与主题检查。正式安装包与 SHA256SUMS.txt 随本 Release 提供。
