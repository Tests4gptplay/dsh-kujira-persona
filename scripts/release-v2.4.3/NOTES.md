# Kujira 2.4.3-rc.2 测试候选

来自 `test/v2.4.3`；本次仅发布预发布包，待用户验证后再转正式版。现有正式版仍为 2.4.2。

## 本次改动

rc.2 修复页面内桌宠右键菜单的定位：当前 DSH 的锚点接口已变化，插件此前只提供旧的定位回调，导致菜单落在页面左上角。本次将菜单锚点关联到桌宠内的实际位置，同时保留旧接口支持，使菜单能随桌宠移动。

菜单样式、三项操作、桌宠与气泡布局及账户查询代码保持 rc.1 原样。

Windows 原生菜单保留原有开始拖拽时关闭的系统交互。Linux/macOS 的 Electron 实现未作改动。

## 安装测试包

在 DSH **插件 → 安装第三方插件 → 包名或地址** 中填写：

```text
https://github.com/Tests4gptplay/dsh-kujira-persona/releases/download/v2.4.3-rc.2/dsh-kujira-persona-2.4.3-rc.2.tgz
```

安装后核对版本为 **2.4.3-rc.2** 并启用。若宿主提示需要重启，保存当前任务后重启 DSH；不要删除 DSH 数据目录。

本候选不发布到 npm。`SHA256SUMS.txt` 提供安装包校验值。

## 验证范围

菜单回归检查实际右键点与菜单坐标的关系，包含移动桌宠后重新打开、页面边缘的合法翻转或夹紧，以及原有隐藏、恢复、关闭和主题操作；分别使用新旧官方公共菜单组件运行。

- 新旧公共菜单组件各通过 11 组浏览器检查，包含真实角色与气泡两种拖拽来源，菜单保持打开时逐帧核对等量移动。
- Linux 实际部署 DSH 0.2.2-rc.3 与本候选插件，使用 XTEST 系统鼠标验证拖动中打开菜单、释放右键后继续拖动，连续 8 帧跟随通过。
- DSH 实际启动 Electron 44.7.0 桌宠，系统鼠标连续拖拽的窗口和菜单坐标同步，隐藏、恢复、全部关闭及切回页面通过。
- macOS 特有的窗口及鼠标穿透分支另做代码与共享控制器契约检查。

发布流程仍运行 rc.1 的账户与恢复回归，逐文件核对安装包源码，并从解包目录验证账户契约。

真实目标机器的安装后效果由本次用户测试确认。
