# 2.0.0 需求补充：桌宠显示 DSH 工作统计

桌宠工作气泡显示 DSH 当前前台会话的统计数据，与宿主底栏保持一致。

## 交付目标

- 页面内与 Windows 桌面桌宠均显示当前前台会话的轮次、步骤、生成速度、累计 Token、缓存命中率、上下文占用。
- 最右侧百分比是上下文已用比例。任务清单进度和账户余额/套餐显示保持独立。
- 在工作气泡中分三行展示，插件设置增加“显示工作统计”，可以独立关闭。任务完成后可保留本会话统计；空闲新会话不显示上个会话的数字。
- 直接复用 DSH 的 `sessionStats`、`tokenUsage`、`contextPressure` 投影，通过已有会话事件更新。不开新的轮询，不扫描日志，不改变模型请求或工具执行。
- 缓存读、缓存写、未缓存输入与输出按 DSH 的分桶相加；思考 Token 已在输出内，不重复相加。缺少速度、用量或上下文容量时省略相应项，不编造为零。
- 切会话清掉旧读数，同一会话切模型仍沿用其累计统计；其他会话或子代理事件不抢占唯一桌宠。

依据：官方 deepseek-ai/deepseek-harness 提交 `687f282e8625c6b8d11ff58211a90524be2e4317` 的 StatsPills.tsx、context-occupancy.ts，以及 session-stats / token-meter 投影定义。

当前前台模型与人物绑定按现有角色目录和用户设置解析；用户明确绑定优先。相关实现见 [catalog.js](../../catalog.js) 和 [pet/controller.js](../../pet/controller.js)。
