# 5. 世界观分层（考据用，别混）

| 层 | 内容 | 能不能当「正史」 |
| --- | --- | --- |
| L0 | 真实产品：DeepSeek、V4.1 Flash、Harness | 是事实，但不是角色 |
| L1 | 造型母题：溟月（上善）→ 女仆鲸鱼娘（ZipZipPipe） | 造型的根，署名链在这 |
| L2 | ZipZipPipe 的梗图与日常（《大AI和小AI们》《AI娘的日常》《"亿万"身家的她们》） | 梗，不是统一人格 |
| L3 | 独立二创宇宙：这个刀子真甜（GPT 小龙娘＋鲸鱼娘日常）、冬冰《AI 中转站公寓》、lieyang《AI 学院》、土豆AX、真不会取名丶 | 各自作者的虚构，互不相通 |
| L4 | 桌宠、PV、MMD、头像、表情包 | 每个媒介自带附加设定 |

**结论：没有唯一正史。** 引用哪一层，就说清是哪一层。
